# AgriNova Admin Dashboard

The AgriNova Admin Dashboard is the administration interface for **Smart Farmer Rwanda**, an AI-powered agricultural advisory platform. It helps administrators manage farmers and monitor agricultural activities.

## Main Features

- Dashboard overview and activity summaries
- Farmer management
- Farm parcel management
- Soil intelligence
- Weather and climate monitoring
- Crop recommendations and suitability assessments
- AI assistant interface
- English and Kinyarwanda language support
- Platform settings

## Technologies Used

- React
- Vite
- JavaScript
- CSS
- Lucide React

## Installation and Setup

1. Open the `frontend` folder.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

## Project Status

This is currently a frontend prototype using sample data. Backend, database, live weather and soil services, and real AI functionality will be integrated in future development.
